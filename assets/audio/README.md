# Audio assets

次の名前は初期プロトタイプで予約していた固定音源スロットです。実ファイルが同梱されていないため、現在の管理画面のBGM / SEドロップダウンには表示されません。

| assetKey | ファイル | 用途 |
| --- | --- | --- |
| `bgm_crowded` | `bgm_crowded.mp3` | 混雑した車内の環境音 |
| `bgm_quiet` | `bgm_quiet.mp3` | 空いた車内の環境音 |
| `se_input` | `se_input.wav` | 選択・決定音 |
| `se_hesitation` | `se_hesitation.wav` | 迷い演出音 |
| `se_reveal` | `se_reveal.mp3` | 結果発表ジングル |

音源を利用する場合は、管理画面の「アセット管理」または各画面イベントのBGM / SE欄から実ファイルをアップロードしてください。アップロード済みの音源だけがプルダウンへ表示されます。
