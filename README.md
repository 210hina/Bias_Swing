# BIAS SWING — 揺れる電車

電車内で「左右どちらの乗客に席を譲るか」を選び、提示情報による判断の変化を体験するWebプロトタイプです。

体験本体に加え、シーン順序、表示時間、設問、背景、BGM／SEなどをブラウザ上で編集・プレビューできる管理画面を備えています。

## 主な機能

- 画面イベントを並べて構成する動的なシーンシーケンス
- 2秒ホールドによる左右の選択操作
- Stage 1「文字のみ」とStage 2「イラスト／他者選択率」の提示
- Stage 2の2α・2β固定表示またはランダム分岐
- 背景レイヤーの永続化とクロスフェード
- 選択時間から算出する迷い度とセッション結果
- 選択直後に、選んだ人物だけを残して結果を伝えるフィードバック演出
- 管理画面でのシーン追加、複製、削除、ドラッグ並び替え
- 各画面の表示時間、背景、字幕、設問、BGM／SE設定
- 画像・音声のカスタムアセット登録と再利用
- 編集中設定のライブプレビューと任意シーンからの再生
- Local Storage保存、JSON Export／Import

## 動作環境

フレームワーク、ビルドツール、npmパッケージは使用していません。HTML、CSS、JavaScript ES Modulesだけで動作します。

- モダンブラウザ（Chrome、Edge、Safari、Firefoxの現行版を推奨）
- ローカルHTTPサーバー

## 起動方法

ES Modulesとブラウザストレージを使用するため、HTMLファイルを直接開かず、プロジェクトのルートでHTTPサーバーを起動してください。

```bash
git clone https://github.com/210hina/Bias_Swing.git
cd Bias_Swing
python3 -m http.server 8000
```

ブラウザで次のURLを開きます。

- 体験本体: <http://localhost:8000/index.html>
- 管理画面: <http://localhost:8000/admin.html>

管理画面と本体は、必ず同じホスト名・ポート番号から開いてください。`localhost:8000`と`127.0.0.1:8000`は別の保存領域として扱われます。

## 体験本体の操作

待機画面でボタンまたはキーを操作するとセッションが始まります。

| 操作 | 選択 |
| --- | --- |
| `←`を2秒ホールド | 左の乗客 |
| `→`を2秒ホールド | 右の乗客 |
| `↓`を2秒ホールド | 自分 |
| 画面の左右ボタンを2秒ホールド | 対応する乗客 |

選択中はボタン中央から外側へゲージが広がり、ホールド完了時に確定します。選択画面は入力が確定するまで待機し、無操作による自動遷移は行いません。

## 管理画面の使い方

管理画面は次のタブで構成されています。

- `イントロダクション`: 開始から導入までの画面イベント
- `シーン 1〜N`: 設問シーンと提示情報
- `結果・サマリー`: 診断結果と終了画面
- `アセット管理`: 再利用する画像・音声ファイル

### 基本的な編集手順

1. 編集するタブを選びます。
2. 画面イベントの時間、背景、字幕、動作種別などを編集します。
3. カード左上のハンドルをドラッグして順序を変更します。
4. カード下部の`＋`から、そのイベントの直後へ新しいイベントを追加します。
5. 右側のタイムライン項目をクリックし、その画面からプレビューします。
6. 本体へ反映する場合は「ブラウザに保存」を押します。

シーンタブでは、シーン全体の追加、複製、削除もできます。

### Stage 2の提示情報

各設問画面では次の提示タイプを選択できます。

| タイプ | 内容 |
| --- | --- |
| 文字のみ | 左右の乗客ラベルのみ |
| 2α：イラスト情報 | 乗客ラベルと人物画像 |
| 2β：他者の選択率 | 乗客ラベル、人物画像、一本の割合バー |
| ランダム分岐 | 2αまたは2βをセッション開始時に選択 |

### 画像・音声アセット

「アセット管理」タブから画像または音声ファイルを登録できます。管理画面上ではすべてファイル名で表示され、内部参照IDは自動生成されます。

- 画像: 背景または人物イラストとして再利用
- BGM: 画面開始時に再生し、ループ、音量、フェードを設定
- SE: 画面開始時または選択確定時に再生

各画面イベントの「開始時BGM」「開始時SE」「選択・アクション時SE」から直接ローカル音源を選ぶこともできます。ここから追加した音源も自動的にアセット管理へ登録され、ほかの画面イベントで再利用できます。

登録ファイルはBase64 Data URLとして設定内に保持され、JSON Exportにも含まれます。大きな画像や音声を多数登録するとLocal Storageの容量上限を超える可能性があるため、その場合はJSON Exportを利用してください。

## 設定の保存と共有

### ブラウザに保存

「ブラウザに保存」を押すと、設定が次のLocal Storageキーへ保存されます。

```text
rocking-train-config-v1
```

同じURLの`index.html`を再読み込みすると保存内容が反映されます。Local StorageはPC、ブラウザ、ホスト、ポートごとに独立しています。

### JSON Export／Import

別のメンバーや別のPCへ設定を渡す場合は、次の手順を使用します。

1. 元の管理画面で「JSON Export」を実行
2. ダウンロードしたJSONを共有
3. 移行先の管理画面で「JSON Import」を実行
4. 内容を確認して「ブラウザに保存」
5. 同じURLの体験本体を再読み込み

カスタム画像・音声もJSON内に含まれるため、管理画面から登録したファイルは原則として別送不要です。

詳しい手順は[CONFIG_JSON_GUIDE.md](./CONFIG_JSON_GUIDE.md)を参照してください。

## 設定データ

現在の設定スキーマはVersion 6です。編集用設定は大きく次の構造を持ちます。

```js
{
  schemaVersion: 6,
  customAssets: {
    images: {},
    audio: {}
  },
  choiceHoldDurationMs: 2000,
  introduction: { sequence: [] },
  questionScenes: [
    {
      id: 'question_scene_01',
      label: 'シーン 1',
      sequence: [],
      questionSet: { stages: [] }
    }
  ],
  result: {
    sequence: [],
    diagnosis: {}
  }
}
```

初期設定は`config-store.js`の`DEFAULT_APP_CONFIG`、本体文言は`content.js`で編集できます。

各画面イベントは`advanceOnInput: true`にすると表示時間を使わず、←／→／↓のいずれかの矢印キー入力で次へ進みます。総合結果画面は初期状態でこの設定が有効です。設問画面はこのフラグとは別に、選択の確定入力を待ちます。

## 開発時の確認

JavaScriptの構文はNode.jsで確認できます。

```bash
node --check admin.js
node --check app.js
node --check config-store.js
node --check content.js
node --check main.js
```

管理画面で変更した設定は、保存前でもライブプレビューへ直接渡されます。タイムラインの任意の画面イベントをクリックすると、その位置から動作確認できます。
